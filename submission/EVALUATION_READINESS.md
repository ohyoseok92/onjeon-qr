## 개발기획서 2절 수정본에 반영할 내용

온전 QR은 기관별 인증·공식 도메인 등록·서버의 Ed25519 서명 발급과 발급 기록 대조로 QR의 출처를 확인한다. 기관·키·QR의 폐기와 만료를 검증하며 상태 변경과 감사 기록은 같은 트랜잭션에 저장한다. 시민 검증 원문과 이동 이력은 저장하지 않는다.

URL 분석은 HTTPS와 공개 IP만 허용하고 DNS의 모든 결과·리다이렉트마다 재검사한 IP에 직접 TLS 연결한다. CA·호스트·유효기간을 검사하며 전체 시간·수신 크기·동시 작업·요청 횟수를 제한한다. 미서명 결과에는 이동 링크를 제공하지 않는다. 숨은 문자·유사 도메인·IDN·인코딩된 설치 확장자도 확인한다.

토큰은 솔트 해시, 개인키는 암호화 PKCS8로 보관하며 운영 모드에서는 비밀 설정을 요구한다. 인증 실패 기록은 원문 IP/토큰을 제외한 제한된 보안 이벤트로 관리한다. 브라우저는 오래된 응답과 카메라 스트림을 정리한다. 공급망은 hash lock·고정 CI action·컨테이너 digest·SBOM·라이선스 전문·제출 manifest로 관리한다.

실제 운영 ACL, HTTPS 프록시, 인증서 해지 확인, 분산 제한, 릴리스 서명, 실물 카메라 및 컨테이너 실행 검증은 남아 있다. 오래된 DB 복원 후 최신 폐기 상태를 반영하기 전에는 서비스를 재개하지 않는다. 상세 구현과 시험은 보안 점검표·시험 보고서를 참조한다.
