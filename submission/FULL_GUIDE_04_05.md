## 이 읽기로 넓힌 점검

기존 검토는 일부 장과 동명 약점 대조에 집중했다. 이번에는 두 문서 전체에서 SBOM 내용의 정확성, 라이선스 전문, 저장소 접근, 개발 PC 상태, CI bootstrap 예외, 복구/업데이트 절차까지 확인했다. CI의 무제한 pip 업그레이드와 editable build isolation을 제거하고 hash lock 설치 뒤 `PYTHONPATH=src`로 시험한다. setup-python이 공급하는 Python/pip와 GitHub runner 자체는 신뢰 기반으로 남으며 hash lock의 범위에 포함시키지 않는다.

전체 5종의 다른 읽기 기록은 `FULL_GUIDE_01.md`, `FULL_GUIDE_02.md`, `FULL_GUIDE_03.md`다. 최종 재검증은 `TEST_REPORT.md`, 운영 확인은 `OPERATION_SECURITY.md`, 동적 점검은 `DAST_CHECK.md`, 복구 결과는 `RECOVERY_CHECK.md`를 기준으로 한다.
