# 온전 QR 제출 안내

## 대회와 결과물

팀 OE-1의 트랙 C 개발 결과물입니다. 기존 개발기획서는 원본을 보존했습니다. 이 압축본은 소스코드, 빌드된 시민 화면, 시험, 시연 스크립트와 보안 설명을 포함합니다. 가상 기관을 사용하므로 실제 공공기관이 참여한 서비스로 소개하지 않습니다.

[공개 운영요강](https://ajou.ac.kr/kr/ajou/notice.do?articleNo=376320&mode=view)에는 2라운드 개발경연 마감이 **2026년 10월 30일 17시**로 적혀 있습니다. 개발경연 중 공지되는 **추가 미션을 포함한 최종 결과물 일체와 소스코드**가 제출 대상입니다. 추가 미션의 내용과 제출 채널·파일 형식은 이 폴더에서 확인되지 않았습니다. 따라서 이 압축본은 미션을 반영하기 전의 제출 후보본이며, 최종 업로드 직전에 해당 공지를 대조해야 합니다.

## 심사 재현 절차

1. 압축을 해제한 뒤 루트 `README.md`의 설치·시험 명령을 실행합니다.
2. `python -m pytest -q`로 서명, 변조 차단, 만료, 폐기, 키 관리, URL 분석과 속도 제한을 검증합니다.
3. `python scripts/demo_flow.py`로 가상 기관 발급 → 신뢰 확인 → 폐기 → 차단 흐름을 재현합니다.
4. `scripts/prepare_demo.py`로 브라우저용 가상 기관을 만들고 `uvicorn`을 실행합니다. 시민 화면에서 QR 원문을 확인한 뒤, 기관 화면에서 새 QR을 발급하고 폐기합니다.
5. 시민 화면에 `https://demo.example.org/notice`를 붙여 넣으면 서명이 없어 경고 상태가 나옵니다. 네트워크가 안 되면 분석 미완료 경고가 나와야 합니다. 미서명 URL의 링크는 제공되지 않습니다.

QR 코드의 `demo.example.org`는 설명용 예약 도메인입니다. 검증 완료 화면의 링크를 열어 실제 서비스를 시연하는 방식은 사용하지 않습니다.

## 제출 직전 확인

- [ ] 예선 통과와 팀 OE-1 참가 상태 확인
- [ ] 경연 중 공지된 추가 미션 구현·시험·설명 반영
- [ ] 운영진이 공지한 제출 채널, 파일명, 용량, 필수 자료 확인
- [ ] `npm run build`로 웹 빌드를 갱신한 뒤 `scripts/build_submission.py` 실행, ZIP 내용과 SHA-256 확인
- [ ] ZIP에 `.secrets`, `.env`, `data`, 개인 증빙서류, 가상환경, `node_modules`가 없는지 확인
- [ ] 실물 휴대폰에서 카메라 권한·QR 스캔 확인

## 알려진 범위

단일 인스턴스 시연용입니다. 기관 승인, 실제 공공기관 도메인 소유 확인, HSM/KMS, 공유 DB, 분산 속도 제한, HTTPS 공개 배포와 동적 웹 보안 진단은 별도 운영 작업입니다. 미서명 URL의 네트워크 분석은 사전 위험 신호일 뿐 페이지 본문이나 이용자의 이후 동작을 보증하지 않습니다. 서명된 QR은 발급 사실을 증명하지만 목적지의 미래 상태를 보증하지 않습니다.
