# 온전 QR 제출 안내

## 공개 시연과 운영 상태

서비스: https://qr.ohs92.com. 실제 공개 TLS·CRL 운영·MYBOX 암호화 백업 왕복 복구·원격 CI를 검증했다. GitHub MFA와 PC C: 암호화도 2026년 10월 11일 사후 확인했다. 자세한 범위와 증거는 [운영 보고서](OPERATIONS_COMPLETION_20261011.md)와 [사후 완료 기록](OPERATIONS_POST_RELEASE_20261011.md)을 따른다. 아래 로컬 시연·초기 점검 기록의 공개 배포 미확인은 후속 보고서로 갱신한다.

## 대회와 결과물

팀 OE-1의 트랙 C 개발 결과물입니다. 기존 개발기획서는 원본을 보존하고, 2026년 10월 21일 업데이트본을 별도 작성했습니다. 이 압축본은 소스코드, 빌드된 시민 화면, 시험, 시연 스크립트와 보안 설명을 포함합니다. 가상 기관을 사용하므로 실제 공공기관이 참여한 서비스로 소개하지 않습니다.

사전교육 자료의 2라운드 마감은 **2026년 10월 30일 18시**입니다. 기존 공개 운영요강의 17시 표기를 교육자료 기준으로 갱신했습니다. 개발 60점·보안 40점이며 제출물은 시연 영상, 수정 개발기획서, 결과 발표자료(PPT·PDF와 하단 대본), 서비스 개요서, 소스코드, 시연 포스터입니다. 영상·수정 개발기획서·결과 발표자료·서비스 개요서·포스터는 상위 `서류/2라운드 제출자료`에 별도로 준비했습니다. 팀 드라이브에 제출한 뒤 Discord에서 완료 여부를 알려야 합니다. 추가 미션은 사용자 지시에 따라 추후 반영하며, 최종 제출 전 운영진의 변경 공지를 확인합니다.

## 심사 재현 절차

1. 압축을 해제한 뒤 루트 `README.md`의 설치·시험 명령을 실행합니다.
2. `python -m pytest -q`로 서명, 변조 차단, 만료, 폐기, 키 관리, URL 분석과 속도 제한을 검증합니다.
3. `python scripts/demo_flow.py`로 가상 기관 발급 → 신뢰 확인 → 폐기 → 차단 흐름을 재현합니다.
4. `scripts/prepare_demo.py`로 브라우저용 가상 기관을 만들고 `uvicorn`을 실행합니다. 시민 화면에서 QR 원문을 확인한 뒤, 기관 화면에서 새 QR을 발급하고 폐기합니다.
5. 시민 화면에 `https://demo.example.org/notice`를 붙여 넣으면 서명이 없어 경고 상태가 나옵니다. 네트워크가 안 되면 분석 미완료 경고가 나와야 합니다. 미서명 URL의 링크는 제공되지 않습니다.
6. 기관 화면에서 발급 목록·집계·감사 이력을 확인하고 QR을 폐기합니다. 폐기 QR을 시민 화면에서 다시 검증하면 차단되며 링크가 없어야 합니다.
7. `npm test --prefix frontend`와 `python scripts/evaluate_product.py`로 화면 회귀 시험과 합성 제품 평가를 재현합니다.

## 보안 검토 자료

교육자료 후반의 49개 보안약점은 `SECURITY_CHECKLIST_49.md`에서 항목별로 확인했습니다. 참고 가이드5종 총1,307쪽의 전체 본문·예제·부록을 읽었으며 `FULL_GUIDE_*.md`에 읽은 범위와 적용 결과를 기록했습니다. 종합 검토는 `GUIDE_SECURITY_REVIEW.md`, 공식 다운로드 출처·해시는 `GUIDE_SOURCES.json`에 있습니다. PDF 원본은 상위 `참고자료/`에 보관합니다. SBOM·공식 스키마·대조 결과·라이선스 전문도 ZIP에 포함했습니다. `DAST_CHECK.md`, `RECOVERY_CHECK.md`, `OPERATION_SECURITY.md`, `EVALUATION_READINESS.md`에는 동적 점검·복구·환경·나머지 평가 항목을 기록했습니다.

QR 코드의 `demo.example.org`는 설명용 예약 도메인입니다. 검증 완료 화면의 링크를 열어 실제 서비스를 시연하는 방식은 사용하지 않습니다.

## 알려진 범위

기존 조건부7개는 `SECURITY_CONDITIONS_REVIEW.md`에서 추가 확인했다. 사후 운영 확인까지 반영한 49개 상태는 구현 확인39·비적용10·조건부0이다. 공개 TLS·CRL 갱신/감시·MYBOX 다운로드 복구·원격 CI는 `OPERATIONS_COMPLETION_20261011.md`, PC C: 암호화와 GitHub MFA는 `OPERATIONS_POST_RELEASE_20261011.md`를 따른다. 운영 비밀·DB·백업은 ZIP에서 제외한다. ZIP 밖의 Ed25519 분리 서명은 독립 채널의 공개키 지문과 최신 ZIP 해시로 검증한다.

단일 인스턴스 공개 시연용입니다. 기관 승인, 실제 공공기관 도메인 소유 확인, HSM/KMS, 공유 DB, 분산 속도 제한과 공개 서비스 전체 침투시험은 별도 범위입니다. 미서명 URL의 네트워크 분석은 사전 위험 신호이며 페이지 본문이나 이용자의 이후 동작을 보증하지 않습니다. 서명된 QR은 발급 사실을 증명하지만 목적지의 미래 상태를 보증하지 않습니다.
